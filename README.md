# 📊 Job Demand Analysis Project

## 📌 Project Overview

The **Job Demand Analysis Project** is a data analysis and visualization project that explores job market trends, in-demand skills, industries, locations, experience levels, and salary patterns.

The project follows a structured data analytics workflow, starting from data loading and cleaning to analysis, visualization, and interpretation of results.

---

## 🎯 Objectives

The main objectives of this project are:

* Analyze job market demand and trends.
* Identify the most in-demand skills.
* Analyze job demand across different industries.
* Study job demand by location.
* Analyze salary patterns across different job roles and experience levels.
* Understand the relationship between experience and job demand.
* Create meaningful visualizations to communicate the findings.
* Generate insights that help understand current job market patterns.

## ▶️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/ananthakalidindi/Job_Demand_Analysis_Project.git
```

### 2. Open the project folder

```bash
cd Job_Demand_Analysis_Project
```

### 3. Install the required Python packages

```bash
pip install -r Job_Demand_Analysis/requirements.txt
```

### 4. Open Jupyter Notebook

```bash
jupyter notebook
```

### 5. Run the notebooks

Run the notebooks in the following order:

1. Data Loading
2. Data Acquisition & Filtering
3. Data Extraction
4. Data Validation & Cleaning
5. Data Aggregation
6. Data Analysis
7. Data Visualization
8. Results Interpretation
